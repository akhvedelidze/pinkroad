# ციფრული ბულვარი

ვარდისფერი მარშრუტი ბათუმში. თამაში, სადაც სპორტული ორიენტირება ჯანმრთელობის სამსახურშია.

მისალმების ეკრანიდან იხსნება თამაშის პირველი მინიშნება ან ბათუმის რუკა. თამაშამდე იწერება გუნდის კოდი და სახელი. სწორ ადგილას იხსნება დავალება: მითი/ფაქტი, ოთხი პასუხი ან ანაგრამა. 50-მდე კითხვა ექვს კატეგორიაშია და გახსნისას შემთხვევით ირჩევა. ტექსტი ჯერ ექიმის დასადასტურებელია. პასუხი ღია ტექსტად არ ინახება. გავლილი პუნქტები რუკაზე ვარდისფერ ხაზად რჩება. ქულა, დრო და მიმდინარე პუნქტი ტელეფონში ინახება, ამიტომ გვერდის განახლების შემდეგ თამაში იქვე გრძელდება. ფინიშზე ჩანს დრო, ქულა, ცდის ნომერი და ფინალური კოდი. „სცადე ხელახლა“ იმავე გუნდით თავიდან იწყებს მარშრუტს და ცდის ნომერს ზრდის. სატესტო გაშვებაში `?debug=1` აჩვენებს მიღების რადიუსს, პუნქტის გამოტოვებას და ქულის შეცვლას. სამუშაო ბილდში ეს რეჟიმი არ შედის.

## გაშვება კომპიუტერზე

```bash
npm install
npm run dev
```

ბრაუზერში გაიხსნება `http://localhost:5173/pinkroad/`. იმავე Wi-Fi-ზე ტელეფონიდან გამოიყენეთ კომპიუტერის ქსელური მისამართი, რომელსაც ტერმინალი დაბეჭდავს.

`npm test` ერთად უშვებს ერთეულოვან ტესტებს და ტელეფონის ეკრანზე სრულ გავლას. ერთეულოვანი ტესტები ამოწმებს გეომეტრიას, ქულას, პაუზას, პროგრესს და ფინალურ კოდს. Playwright 390×844 ეკრანზე, დებაგ-რეჟიმით, გუნდს ატარებს ყველა პუნქტზე და ფინიშის კოდამდე.

## სამი ბილდი

| ბრძანება | რა გამოდის |
|---|---|
| `npm run dev` | განვითარება, მისალმების ეკრანი |
| `npm run build:staging` | სატესტო ბილდი `dist-staging/`-ში, ეკრანზე ჩანს ბანერი „დაუდასტურებელი კონტენტი“ |
| `npm run build:prod` | სამუშაო ბილდი `dist/`-ში, ბანერის გარეშე |

სატესტო ბილდის სანახავად: `npm run preview:staging`. სამუშაო ბილდის სანახავად: `npm run preview`.

`npm run check:content` ამოწმებს კონტენტის სტრუქტურას და გადაფარულ რადიუსებს. `npm run build:prod` დამატებით ჩერდება დაუდასტურებელ კოორდინატზე, დაუდასტურებელ სამედიცინო ტექსტზე და `[[DOCTOR_FILL]]`-ზე.

## ფინალური კოდი

ფინიშის ეკრანზე ჩანს კოდი: გუნდის კოდი, ცდის ნომერი, წამები, ქულა და საკონტროლო ნიშანი. ორგანიზატორი ამოწმებს ასე:

```bash
npm run verify -- --code ROSE.1.1200.86.a1b2c3d4 --name "ვარდისფერი"
```

`1` პირველი ცდაა. „სცადე ხელახლა“ ამ რიცხვს ზრდის. თუ ტელეფონზე შენახულ მონაცემებს წაშლიან, მთვლელი ისევ პირველი ცდიდან იწყება.

სახელი ზუსტად ის უნდა იყოს, რაც ეკრანზე წერია. თუ კოდში ქულა ან დრო შეცვლილია, ბრძანება წერს „კოდი არ დადასტურდა“. თუ დრო 15 წუთზე ნაკლებია, კოდი მაინც შეიძლება სწორი იყოს, მაგრამ ეკრანზე გამოდის გაფრთხილება და ორგანიზატორმა შედეგი ადგილზე უნდა დაადასტუროს.

ეს კოდი შემაკავებელია, სრულად გაუტეხავი არ არის. საზომი ნიშანი თამაშის ფაილშივეა, ამიტომ ტელეფონზე შენახული ქულის შეცვლა ახალ სწორ კოდს დააგენერირებს. ორგანიზატორი გუნდს ადგილზე ადასტურებს.

## რუკა

რუკა იხატება OpenStreetMap-ის მონაცემებიდან ბრძანებით `npm run map:render`. საზღვარი არის ბათუმის ადმინისტრაციული არეალი, რომელსაც Nominatim აბრუნებს. ღირსშესანიშნაობების სახელები რუკაზე არ წერია. გადიდებისას ჩანს მთავარი ქუჩები, მაგალითად რუსთაველის, ჭავჭავაძის, ხალვაშის და აეროპორტის გზა. ღილაკი „შემოწმება“ აჩვენებს სანიშნეებს. სამი დადასტურებული ადგილი და ექვსი ჯერ დაუდასტურებელი პუნქტი (`verified: false`) ერთ სიაშია.

## სად დევს ფონტი

ქართული ტექსტი იყენებს Noto Sans Georgian-ს (`public/fonts/`, woff2). გაშვებისას ფონტი სხვა საიტიდან არ იტვირთება.

## ჰოსტინგი

საჯარო მისამართია `https://akhvedelidze.github.io/pinkroad/`. GitHub Action `npm run build`-ით აწყობს საიტს და აქვეყნებს. საკუთარი დომენი მერე მიებმება.

## კითხვების შეცვლა

კოდის შეცვლა არ გჭირდებათ.

- ადგილი, მინიშნება და ეტაპი: `content/points.json`
- კითხვა პუნქტზე: `content/tasks.json`
- საერთო ბანკი, საიდანაც შემთხვევითი კითხვა ირჩევა: `content/questions.json`
- ქულა, პაუზა და რადიუსი: `content/config.json`

სამედიცინო ტექსტში ციფრის ადგილას წერია `[[DOCTOR_FILL]]`. სანამ ექიმი არ დაადასტურებს, `reviewed` რჩება `false`. სწორი პასუხი ფაილში ღია ტექსტად არ წერია. ახალი პასუხის ჰეში ასე მიიღება:

```bash
npm run hash:answer -- "სწორი პასუხი"
```

გამოტანილი `salt` და `answerHash` ჩასვით კითხვის ვარიანტში. შემდეგ გაუშვით `npm run check:content`.

`npm run build:prod` ჩერდება, თუ კოორდინატი ან ტექსტი დაუდასტურებელია, ტექსტში `[[DOCTOR_FILL]]` რჩება, ან ორი პუნქტის რადიუსი ერთმანეთს ფარავს. სატესტო ბილდი ამის გამო არ ჩერდება.
